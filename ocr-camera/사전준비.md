# 세션 전에 해올 것 — 카메라 OCR

**세션 시간에 설치하면 2시간이 설치로 끝납니다.** 미리 해오세요.
받는 게 대부분이라 오래 걸립니다. 와이파이 되는 데서 미리 돌려두세요.

준비물: 노트북, **실물 폰**(시뮬레이터는 카메라가 없습니다), 노트북과 폰 둘 다 같은 와이파이.

---

## 1. Node.js 설치

Expo가 Node 위에서 돕니다. 없으면 아무것도 안 됩니다.

https://nodejs.org 에서 **LTS** 버전을 받아서 설치합니다.

윈도우는 이것도 됩니다. (PowerShell)

```powershell
winget install OpenJS.NodeJS.LTS
```

설치 후 **터미널을 새로 열고** 확인합니다. 새로 안 열면 안 잡힙니다.

```bash
node --version
npm --version
```

`v20` 이상이면 됩니다. 트랙장 노트북에서 확인한 조합은 **Node v24.19.0 / npm 11.17.0** 입니다.

`npm notice New major version of npm available` 같은 안내가 떠도 무시하세요. 안 올려도 됩니다.

---

## 2. Expo 프로젝트 만들기

```bash
npx create-expo-app ocr-app --template blank
cd ocr-app
npx expo install expo-camera
```

`npm install`이 3~5분 걸립니다. 여기가 제일 오래 걸리는 구간입니다.

설치가 끝나면 `10 moderate severity vulnerabilities` 같은 경고가 나옵니다. **그냥 두세요.**
Expo 기본 템플릿에서 원래 나오는 것이고, `npm audit fix --force`를 돌리면 버전이 어긋나서
오히려 앱이 안 뜹니다.

확인:

```bash
npx expo start
```

QR이 뜨면 성공입니다. `Ctrl+C`로 끄세요.

트랙장 노트북에서 확인된 버전은 **Expo SDK 57 / expo-camera 57 / React Native 0.86** 입니다.
`npx create-expo-app`이 알아서 맞춰주니 버전을 직접 지정하지 마세요.

## 4. 파이썬 쪽 설치

```bash
pip install fastapi "uvicorn[standard]" python-multipart pillow rapidocr onnxruntime
```

그리고 **OCR 모델을 미리 받아둡니다.** 이걸 안 하면 세션장에서 처음 실행할 때
수십 MB를 받느라 멈춰 있습니다.

아무 데나 `warmup.py`로 저장하고 한 번 돌리세요.

```python
import numpy as np
from rapidocr import LangRec, ModelType, OCRVersion, RapidOCR

engine = RapidOCR(params={
    "Rec.lang_type": LangRec.KOREAN,
    "Rec.ocr_version": OCRVersion.PPOCRV4,
    "Rec.model_type": ModelType.MOBILE,
})
engine(np.full((64, 256, 3), 255, dtype=np.uint8))
print("모델 준비 끝")
```

```bash
python warmup.py
```

`모델 준비 끝` 이 나오면 됩니다.

중간에 `The text detection result is empty` 라는 노란 경고가 뜨는데 정상입니다.
빈 이미지를 넣었으니 글자를 못 찾는 게 맞습니다. 모델을 받는 게 목적입니다.

## 5. 방화벽 열기 (윈도우만)

폰에서 내 노트북으로 들어와야 하는데, 윈도우가 기본으로 막습니다.

PowerShell을 **관리자 권한으로** 열고 한 번만:

```powershell
New-NetFirewallRule -DisplayName "OCR demo" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow -Profile Any
```

맥은 안 해도 됩니다. 서버 처음 띄울 때 허용 창이 뜨면 **허용**을 누르세요.

세션 끝나고 되돌리기:

```powershell
Remove-NetFirewallRule -DisplayName "OCR demo"
```

## 체크리스트

세션 오기 전에 다섯 개 다 O가 되어야 합니다.

| | 확인 방법 | 나와야 하는 것 |
|---|---|---|
| Node | `node --version` | `v20` 이상 |
| Expo 프로젝트 | `npx expo start` | QR 코드 |
| Expo Go | 폰에서 앱 실행 | 열림 |
| 파이썬 | `python warmup.py` | `모델 준비 끝` |
| 방화벽 | 관리자 PowerShell에서 위 명령 | 에러 없이 끝남 |

**하나라도 안 되면 세션 전에 말해주세요.** 당일에 고치면 그 사람은 그날 못 합니다.
